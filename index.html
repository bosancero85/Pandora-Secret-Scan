Pandora® Secret SCAN

Findet API-Keys, Tokens und private Schlüssel in deinem Code – bevor sie im Repository landen. Lokal, schnell und ohne Cloud.

Zu den Downloads ↓

  • Muster-ErkennungAnthropic- und OpenAI-Keys, AWS Access Key IDs, GitHub-Tokens, private Schlüssel und Zuweisungen wie api_key = "…".
  • Entropie-AnalyseOptional: erkennt auch unbekannte Zufallstokens anhand der Shannon-Entropie.
  • Bleibt bedienbarDer Scan läuft im Hintergrund – mit Fortschrittsbalken, Statusprotokoll und Stopp-Knopf.
  • LokalAlles läuft auf deinem Rechner. Dateien und Fundstellen werden nicht versendet.
  • JSON-ReportFundstellen mit Datei, Zeile, Typ und Entropie als JSON exportieren.
  • Sinnvolle VorgabenÜberspringt .git-Ordner und Binärdateien wie Bilder, Archive und Programme.

So startest du

  1. Datei für dein System herunterladen.
  2. Starten – unter Linux zuerst chmod +x Pandora-Secret-Scan-Linux.AppImage ausführen.
  3. Projektordner wählen, Scan starten, Treffer prüfen und bei Bedarf den Report als JSON exportieren.

Hinweise: Die Programme sind nicht signiert. Windows zeigt ggf. eine SmartScreen-Meldung („Weitere Informationen“ → „Trotzdem ausführen“), manche Virenscanner lösen bei selbst gebauten EXE-Dateien einen Fehlalarm aus; macOS verlangt beim ersten Start Rechtsklick → „Öffnen“. Bei Ubuntu ab 22.04 braucht ein AppImage ggf. sudo apt install libfuse2. Treffer sind Verdachtsfälle, keine Beweise – und der JSON-Report enthält Fundstellen im Klartext, behandle ihn wie ein Secret.

Aus dem Quellcode starten

Für andere Systeme oder zum Ausprobieren – benötigt Python 3.10 oder neuer und PyQt6:

git clone https://github.com/bosancero85/Pandora-Secret-Scan.git
cd Pandora-Secret-Scan
pip install -r requirements.txt
python pandora_secret_scan.py
